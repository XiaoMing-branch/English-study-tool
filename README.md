# Keykey

专为嵌入式软件工程师设计的专业英语词汇学习助手。内建 83 词专业词库，并通过 Open English Dictionary (OED) 在线词典提供 25,000+ 单词的丰富释义、例句和近义辨析。学习数据存储在本地浏览器，无需注册。

---

## 功能特性

- **学习概览仪表盘** — 待复习单词数、今日已学、连续学习天数、总体掌握率一目了然
- **83 词专业词库** — 覆盖嵌入式核心、汽车通信协议、硬件接口、编程基础、存储与内存、调试与测试、汽车功能安全、通信技术、实时操作系统等 9 个分类
- **闪卡模式 (SRS)** — 基于间隔重复算法，看中文释义回忆英文单词，自评掌握程度，系统自动安排下次复习时间
- **拼写模式** — 根据中文释义输入英文单词，提交后获得字符级差异高亮反馈
- **测验模式** — 选择题（中译英/英译中）+ 填空题混合出题，附带错题回顾功能
- **词汇浏览器** — 全文搜索、按分类/掌握等级过滤，点击单词查看详细释义和代码示例
- **学习统计** — 等级分布条形图、每日学习记录、掌握率趋势
- **丰富设置** — 每日学习目标、复习方向、深浅主题切换、字号调节、测验题目数量
- **数据导入/导出** — JSON 格式一键备份和还原，方便跨设备迁移
- **在线词典查询** — 基于 Open English Dictionary (MIT)，通过 CDN 获取 25,000+ 单词的丰富释义、例句和近义辨析

## 使用说明

### 基础操作

| 操作 | 方法 |
|------|------|
| 切换功能页面 | 点击顶部导航栏标签 |
| 开始复习 | 首页点击「开始复习」→ 进入闪卡模式 |
| 学习新词 | 首页点击「学习新词」→ 进入词汇浏览器 |
| 打开设置 | 点击右上角齿轮图标 |

### 闪卡模式

1. 选择导航栏「**闪卡**」标签，或首页点击「**开始复习**」
2. 查看中文释义，尝试回忆对应的英文单词
3. **点击卡片** 或按 **空格键** 翻转，查看正确答案
4. 根据实际掌握情况，点击 5 级评级按钮自评：
   - **不认识** — 完全没见过
   - **有印象** — 见过但想不起来
   - **不会用** — 认识但拼写/用法不熟
   - **基本会** — 能回忆出来
   - **完全会** — 熟练掌握
5. 系统自动进入下一张卡片，并根据你的自评调整复习计划

**快捷键**：Space 翻牌 | 1-5 评级 | Escape 关闭弹窗

### 拼写模式

1. 选择导航栏「**拼写**」标签
2. 看到中文释义后，在输入框中输入英文单词
3. 按 **Enter** 键或点击「**提交**」
4. 查看字符级差异高亮反馈（绿色 = 正确字母，红色 = 错误字母）
5. 答错时会显示正确答案，2 秒后自动进入下一题

### 测验模式

1. 选择导航栏「**测验**」标签
2. 点击「**开始测验**」按钮
3. 回答选择题和填空题（共 10-20 题，可在设置中调整）
4. 每道题即时显示对错反馈
5. 完成后查看得分、正确率和**错题回顾**
6. 点击「**再来一次**」可重新生成新测验

### 词汇浏览

1. 选择导航栏「**词汇**」标签
2. **搜索**：在搜索框中输入英文或中文关键词
3. **筛选**：使用下拉菜单按分类或掌握等级过滤
4. **查看详情**：点击任意词汇卡片，弹出详情窗口（含定义、代码示例、学习统计）

## 数据管理说明

### 数据存储位置

所有学习数据（词汇、学习状态、设置、每日记录）均存储在浏览器的 **localStorage** 中，不会上传到任何服务器。导出备份文件统一采用 `user_data/` 命名前缀，便于识别和管理。

### 导出数据

1. 点击右上角 ⚙ → **导出数据**
2. 浏览器会自动下载一个 JSON 文件（文件名格式：user_data/keykey-backup-YYYY-MM-DD.json）
3. 建议**定期导出**备份，以防浏览器数据被意外清除

### 导入数据

1. 点击右上角 ⚙ → **导入数据**
2. 选择之前导出的 JSON 文件
3. 确认导入后，学习记录和设置将恢复到备份时的状态

### 重置数据

1. 点击右上角 ⚙ → **重置所有数据**
2. 在确认对话框中点击「**确认重置**」
3. 所有学习记录、进度和设置将被清除，页面自动刷新后重新初始化

> ⚠ **警告**：重置操作不可撤销！建议在重置前先导出数据备份。

## SRS 间隔重复算法

本工具采用**间隔重复（Spaced Repetition System）**算法管理词汇复习节奏：

| 掌握等级 | 含义 | 下次复习间隔 |
|----------|------|-------------|
| Level 0 | 完全不认识 | 10 分钟 |
| Level 1 | 有点印象 | 1 小时 |
| Level 2 | 认识但不会用 | 1 天 |
| Level 3 | 基本掌握 | 3 天 |
| Level 4 | 完全掌握 | 7 天 |

连续答对 3 次（Level 4）后，单词标记为「已毕业」，不再出现在复习队列中。

## 技术架构

- **纯前端应用** — 无后端、无数据库、无服务器
- **单文件 SPA** — index.html 包含所有 HTML/CSS/JavaScript
- **在线词典数据** — 通过 jsDelivr CDN 获取 Open English Dictionary 数据，支持 25,000+ 单词查询
- **localStorage 持久化** — 所有数据存储于浏览器本地
