# Keykey首页开发描述文档
> 本文档用于向 AI 准确描述 [keykey.cc/dash](keykey.cc/dash) 页面的完整结构与设计，以便开发出完全一致的页面。
---
## 一、页面整体概述
**网站名称**：Keykey（标语：学英语 一个就够）
**页面路径**：/dash（首页 / 仪表盘）
**页面类型**：英语学习工具类网站首页
**核心功能**：英语单词查询
**设计风格**：极简清爽、工具导向、黑白灰配色、卡片式布局
---
## 二、整体布局结构
页面采用 **左侧可折叠侧边导航栏 + 右侧主内容区** 的双栏布局：
```Plain
┌─────────────┬──────────────────────────────────┐
│             │                                  │
│  侧边栏     │         主内容区                  │
│  (可折叠)   │                                  │
│             │                                  │
│             │                                  │
└─────────────┴──────────────────────────────────┘
```
- **侧边栏**：固定宽度，白色背景，可折叠 / 展开
- **主内容区**：占据剩余宽度，浅灰白色背景（#fafafa 或类似）
- **内容居中**：主内容区的卡片模块水平居中，宽度约占主内容区的 70-80%
- **内容分布**：页面内容较少，仅两个卡片模块，垂直居中偏上排列，卡片下方为大面积空白区域
---
## 三、左侧侧边导航栏（详细描述）
### 3.1 侧边栏整体特性
- **背景色**：纯白色
- **宽度**：展开状态约 200-240px
- **折叠状态**：仅显示图标，宽度约 60-80px
- **定位**：固定定位，高度 100% 视口高度
- **触发方式**：页面最左侧边缘有一个小的灰色竖条，点击展开侧边栏
- **展开方式**：覆盖式展开（overlay），侧边栏展开时覆盖在主内容区上方
- **遮罩层**：侧边栏展开时，主内容区会显示半透明灰色遮罩层
- **关闭方式**：点击 X 按钮或点击遮罩层均可收起侧边栏
### 3.2 顶部区域
从上到下依次为：
| 元素     | 描述                                                               |
| -------- | ------------------------------------------------------------------ |
| 网站标识 | 左侧：黑色多面体 / 几何图标+ 文字「[keykey.cc](keykey.cc)」 |
| 主题切换 | 中间：太阳形状图标（用于明暗主题切换）                             |
| 折叠按钮 | 右侧：「X」形状图标，点击可折叠 / 关闭侧边栏                       |
### 3.3 主导航菜单（共 7 项）
每项为 **图标 + 文字** 的组合，垂直排列：
| 序号 | 导航项   | 图标样式                | 状态                        |
| ---- | -------- | ----------------------- | --------------------------- |
| 1    | 首页     | 房屋形状图标            | ✅ 当前激活，浅灰色背景高亮 |
| 2    | 单词练习 | 键盘形状图标            | 默认状态                    |
| 3    | 句子练习 | 学士帽 / 毕业帽形状图标 | 默认状态                    |
| 4    | 资源中心 | 文件夹形状图标          | 默认状态                    |
| 5    | 复习中心 | 文档 / 笔记本形状图标   | 默认状态                    |
| 6    | 发音学习 | 喇叭形状图标            | 默认状态                    |
| 7    | 知识文章 | 字母 A+ 对勾组合图标   | 默认状态                    |
**交互说明**：
- 鼠标悬停时有浅灰色背景反馈
- 当前页（首页）有持续的浅灰色背景高亮
- 文字颜色：深灰色 / 黑色
### 3.4 次级导航菜单（共 3 项）
由一条**浅灰色水平分隔线**与主导航隔开：
| 序号 | 导航项   | 图标样式            |
| ---- | -------- | ------------------- |
| 1    | 学习统计 | 柱状图 / 条形图图标 |
| 2    | 个人中心 | 单人轮廓图标        |
| 3    | 共建计划 | 双人轮廓图标        |
### 3.5 底部推广卡片
侧边栏最底部有一个虚线边框的卡片：
- **标题**：「看视频・学语言」
- **副标题**：「语境功能 公测启动」
- **按钮**：「点此参与」（浅灰色背景按钮）
- **边框**：虚线边框样式
- **图标**：左侧有一个对话气泡样式的线性图标

## 四、右侧主内容区（详细描述）
主内容区包含**两个主要模块**，垂直排列，模块之间有间距。
### 4.1 模块一：查英语单词（核心功能）
#### 整体外观
- **容器**：白色卡片，带圆角（约 8-12px），极淡的边框
- **内边距**：上下左右有充足的内边距
- **宽度**：占据主内容区大部分宽度
#### 4.1.1 标题说明区
| 元素         | 位置       | 样式                                         |
| ------------ | ---------- | -------------------------------------------- |
| 主标题       | 左上角     | 「查英语单词」，黑色加粗字体，字号较大       |
| 副标题       | 主标题下方 | 「词义、音标、例句」，灰色小字，说明功能范围 |
| 搜索图标按钮 | 右上角     | 浅灰色圆形 / 圆角方形按钮，内含放大镜图标    |
#### 4.1.2 搜索输入区
| 元素     | 描述                                                                              |
| -------- | --------------------------------------------------------------------------------- |
| 输入框   | 长条形，占据卡片横向全宽，浅灰白色背景（#f5f5f5），圆角设计                      |
| 占位符   | 英文小写`search`，灰色文字                                                      |
| 查询按钮 | 位于输入框最右侧，深黑色填充，圆角矩形；左侧白色放大镜图标+ 右侧白色「查询」文字 |
**交互**：
- 点击「查询」按钮触发查询
- 键盘按 Enter 键也可触发查询
#### 4.1.3 结果展示区
- **位置**：输入框下方
- **背景**：浅灰白色（比输入框略浅或相同）
- **高度**：面积较大的矩形区域
- **圆角**：带圆角
- **默认状态**：区域内居中显示灰色提示文字「输入英文词条后查询」
- **查询后**：展示单词详情内容（词义、音标、例句等）
---
### 4.2 模块二：页面异常处理
#### 整体外观
- **容器**：白色卡片，带圆角，与上方查词卡片风格一致
- **宽度**：与上方查词卡片相同
- **高度**：比查词卡片矮很多
#### 内容布局
采用左右布局：
- **左侧文字区**：
  - 标题：「页面异常处理」，黑色加粗
  - 说明文字：「遇到白屏、旧版本资源或缓存异常时，可先清理本地资源缓存并刷新页面。」灰色小字
- **右侧按钮区**：
  - 按钮：「立即修复」，浅灰色背景，圆角
  - 图标：按钮左侧有一个刷新 / 循环箭头图标

## 五、设计风格规范
### 5.1 配色方案
| 用途          | 颜色                              |
| ------------- | --------------------------------- |
| 主背景        | 浅灰白色（#fafafa / #f9f9f9）   |
| 卡片背景      | 纯白色（#ffffff）                |
| 主文字        | 深灰近黑（#333333 / #1a1a1a）   |
| 次要文字      | 中灰色（#666666 / #888888）     |
| 提示文字      | 浅灰色（#999999 / #aaaaaa）     |
| 主按钮        | 纯黑色背景+ 白色文字             |
| 次按钮        | 浅灰色背景+ 深灰色文字           |
| 激活状态      | 浅灰色背景（#f0f0f0 / #f5f5f5） |
| 边框 / 分隔线 | 极浅灰色（#eeeeee / #e5e5e5）   |
### 5.2 圆角规范
- 卡片圆角：约 8-12px
- 按钮圆角：约 6-8px
- 输入框圆角：约 6-8px
### 5.3 字体规范
- 字体：无衬线字体（系统默认 sans-serif）
- 标题：加粗
- 正文：常规字重
- 整体字号：偏小，工具类网站风格
### 5.4 间距规范
- 模块之间：较大间距（约 24-32px）
- 模块内部：适中内边距（约 20-24px）
- 元素之间：小间距（约 8-16px）

## 九、项目经理视角：产品功能描述
### 9.1 产品概述
#### 9.1.1 产品定位
**Keykey** 是一款面向英语学习者的在线工具类产品，以"学英语 一个就够"为核心理念，致力于为用户提供极简、高效、专注的英语学习体验。产品以单词查询为核心入口，逐步拓展至全方位的英语学习场景。
#### 9.1.2 目标用户
- **核心用户**：有英语学习需求的学生、职场人士及英语爱好者
- **使用场景**：日常单词查询、英语阅读辅助、词汇积累与复习
- **用户特征**：追求效率、偏好简洁工具、反感冗余信息干扰
#### 9.1.3 核心价值主张
1. **极简高效**：进入即用，无需复杂注册和学习成本
2. **专注学习**：黑白灰配色，无广告干扰，专注学习本身
3. **功能完整**：从查词到练习、复习、发音，覆盖学习全链路
4. **体验一致**：统一的设计语言和交互模式，降低认知成本

### 9.3 首页功能详细描述
#### 9.3.1 页面定位
首页（/dash）是用户进入产品后的第一触点，承担以下核心使命：
1. **功能入口**：提供最核心的单词查询功能
2. **导航分发**：引导用户进入其他功能模块
3. **品牌传达**：传递极简、专业的产品形象
#### 9.3.2 核心功能：单词查询
**功能目标**：让用户以最短路径完成单词查询，获取词义、音标、例句等核心信息。
**功能组成**：
| 功能点   | 详细说明                             | 用户价值               |
| -------- | ------------------------------------ | ---------------------- |
| 搜索输入 | 支持英文单词输入，Enter 键或按钮提交 | 快速输入，降低操作成本 |
| 词义展示 | 展示单词的多词性中文释义             | 理解单词核心含义       |
| 音标标注 | 显示国际音标，支持发音播放           | 掌握正确发音           |
| 例句学习 | 提供多场景中英对照例句               | 学习实际用法           |
| 结果引导 | 默认状态提示"输入英文词条后查询"     | 降低新用户学习成本     |
**用户流程**：
```
用户进入首页 → 看到搜索框 → 输入单词 → 点击查询/按Enter → 查看结果详情
```
#### 9.3.3 导航系统
**设计理念**：可折叠侧边栏，既保证功能完整性，又不干扰主任务。
**导航结构**：
| 层级 | 导航项   | 功能说明                    |

| 一级 | 句子练习 | 进入句子翻译与练习模块      |
| 一级 | 资源中心 | 浏览学习资源汇总            |
| 一级 | 复习中心 | 进入单词复习（SRS间隔重复） |
| 一级 | 发音学习 | 进入音标与发音练习          |

| 二级 | 学习统计 | 查看个人学习数据            |

- **默认折叠**：侧边栏默认收起，仅在左边缘露出提示条
- **点击展开**：点击边缘竖条展开完整导航
- **展开方式**：覆盖式展开（overlay），展开时主内容区显示半透明灰色遮罩层
- **关闭方式**：点击 X 按钮或遮罩层均可收起侧边栏
- **状态记忆**：（建议）记住用户的折叠/展开偏好
- **当前高亮**：当前所在页面高亮显示，清晰定位
#### 9.3.4 页面异常处理
**功能目标**：提供自助式问题解决方案，降低用户流失和客服压力。
**功能说明**：
- 针对白屏、旧版本资源、缓存异常等常见问题
- 提供"立即修复"一键清理缓存功能
- 位置：首页底部，不干扰正常使用

### 9.4 交互设计规范
#### 9.4.1 布局原则
1. **内容优先**：主内容区占据最大视觉权重
2. **导航可隐**：侧边栏可折叠，为内容腾出空间
3. **视觉聚焦**：核心功能（查词）位于视觉中心
4. **呼吸感**：充足的留白和间距，避免拥挤
#### 9.4.2 视觉风格
- **配色方案**：黑白灰三色体系，极简专业
- **卡片设计**：白色卡片 + 圆角 + 淡边框，层次分明
- **按钮体系**：主按钮黑色高权重，次按钮灰色低权重
- **字体选择**：无衬线字体，保证可读性和现代感
#### 9.4.3 交互要点
1. **即时反馈**：按钮悬停、点击都有视觉反馈
2. **键盘支持**：核心操作支持键盘快捷键（如 Enter 查询）
3. **状态清晰**：激活态、悬停态、默认态区分明确
4. **容错设计**：异常情况有明确的处理入口

### 9.5 发音学习功能详细描述
#### 9.5.1 功能定位
发音学习是 Keykey 核心学习闭环的重要组成部分，针对用户"听得懂、说得出"的发音学习需求，提供系统化的发音训练解决方案。
#### 9.5.2 目标用户
- 希望改善英语发音的学习者
- 准备英语口语考试的学生
- 需要提升职场英语沟通能力的职场人士
#### 9.5.3 核心功能模块

| 音标学习 | 国际音标系统学习，包含发音口型、舌位讲解 | 掌握发音基础，从根源改善发音 |

| 跟读练习 | 录音跟读，与原音对比评分 | 实战练习，即时反馈 |
| 视频讲解 | 发音教学视频，专业老师讲解发音技巧 | 可视化学习，更易理解 |
#### 9.5.4 用户入口与流程
```
用户点击发音学习 → 进入发音学习主界面 → 选择学习内容 → 开始学习
```
#### 9.5.5 产品亮点
1. **经典教材**：采用新概念英语作为核心学习材料，体系成熟
2. **多维度学习**：从音标基础到实际应用，覆盖发音学习全链路
3. **即时反馈**：跟读练习提供即时评分反馈，提升练习效率
4. **视频讲解**：专业视频讲解，降低发音学习门槛

2. **即开即用**：无需登录即可使用核心查词功能
